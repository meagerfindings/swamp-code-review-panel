# swamp-code-review-panel

[swamp](https://swamp.club) extension `@mgreten/code-review-panel` — run a panel of reviewer personas over one body of code and get unified, actionable findings.

📖 **Extension documentation:** [extensions/models/README.md](extensions/models/README.md)

📦 **Install:** `swamp extension pull @mgreten/code-review-panel`

## Repository layout

This repository is a swamp workspace (its own `.swamp.yaml` repo). The
publishable extension lives under [extensions/models/](extensions/models/).
